voxlingua107

Detect which of 107 languages someone is speaking, in Node.js, Bun or the browser. Try it: everything below runs on your device, and no audio leaves your browser.

GitHub npm Docs
Say something
in any language

The model (87 MB) downloads the first time you use it and is cached after that.

    Live mode looks at the last 6 seconds of audio. Accuracy drops on clips under about 3 seconds, so keep talking for a moment.

    Docs

    Install

    npm install voxlingua107          # Node.js / Bun
npm install voxlingua107 onnxruntime-web   # browser

    Node.js and Bun

    import { readFile } from "node:fs/promises";
import { LanguageIdentifier, decodeWav } from "voxlingua107";

const lid = await LanguageIdentifier.load(); // downloads the model once (~87 MB)
const { samples, sampleRate } = decodeWav(await readFile("speech.wav"));

const result = await lid.identify(samples, { sampleRate });
console.log(result.code, result.name, result.probability); // "es" "Spanish" 0.97

    Runs natively on CPU via onnxruntime-node: about 50 ms for 10 seconds of audio. Accepts Float32Array or 16-bit PCM Int16Array at any sample rate.

    Browser

    import { LanguageIdentifier } from "voxlingua107/web";

const lid = await LanguageIdentifier.load({
  onProgress: (loaded, total) => console.log(loaded / total),
});
const result = await lid.identify(samples, { sampleRate: 48000 });

    Same API, running on WebAssembly. The model is checked against a pinned SHA-256 and kept in Cache Storage, so it downloads once. If your bundler doesn't serve onnxruntime-web's .wasm files, pass wasmPaths: "https://cdn.jsdelivr.net/npm/onnxruntime-web@1.30.0/dist/".

    Streams (Pipecat, WebRTC, telephony)

    // 16-bit PCM frames, any sample rate. Collect a few seconds first.
const result = await lid.identify(pcmInt16, { sampleRate: 24000 });

// Only choose between the languages you support:
await lid.identify(pcmInt16, { sampleRate: 24000, candidates: ["en", "es", "ca"] });

    candidates and result.code use the LanguageCode type, a union of all 107 codes, so typos are compile errors.

    Results

    MethodReturns
    identify(audio, { sampleRate, topK, candidates }){ code, name, probability, top }; top is the topK best, best first
    embed(audio)256-dim language embedding (Float32Array)
    run(audio)raw { logits, embedding }; logits are log-probabilities in LANGUAGES order
    dispose()frees the ONNX Runtime session

    Where the model is stored

    Node / Bun optionWhat it does
    cacheDirCache folder. Defaults to $VOXLINGUA107_CACHE_DIR, then ~/.cache/voxlingua107.
    modelPathUse a local .onnx file; nothing is downloaded.
    download: falseFail instead of downloading (offline, serverless).

    For Docker images, download at build time:

    ENV VOXLINGUA107_CACHE_DIR=/models
RUN npx voxlingua107 download

    Accuracy

    The model is SpeechBrain's VoxLingua107 ECAPA-TDNN, with a 6.7% error rate on the VoxLingua107 dev set. The test suite checks this package against the original PyTorch model: probabilities agree within 6×10⁻⁶. It works best on a few seconds of clear speech, and it was trained on YouTube audio, so strong accents, children's speech and smaller languages are harder.

    The full documentation is in the README.
